# Ayesha Bashir – Personal Portfolio

My capstone project for the D4WEE (Digital 4 Web & Employability Excellence) Web Development & Data Analytics track.

**Live site:** https://YOUR-USERNAME.github.io/ayesha-portfolio/

## About
A responsive personal portfolio with a hero, about me, skills, projects and contact section.

## Tech used
- HTML5 (semantic tags)
- CSS3 (Flexbox, CSS Grid, media queries, CSS variables)
- Vanilla JavaScript (no frameworks)

## Features
- Responsive layout for mobile, tablet and desktop
- Mobile hamburger menu
- Dark / light mode toggle (remembers your choice)
- Typing effect in the hero
- Animated skills chart on page load
- Project filter buttons (All / Web / Data)
- Contact form with validation
